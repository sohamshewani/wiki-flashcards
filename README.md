# Wiki-Flashcards

A CLI utility to generate personalized flashcard decks from Wikipedia articles for efficient learning.

## Installation

```bash
pip install git+https://github.com/username/wiki-flashcards.git
```

## Usage

```bash
wiki-flashcards <article-title>
```

## Example

```bash
wiki-flashcards python
```

This command will generate a flashcard deck for the Wikipedia article on 'Python'.
